Colour

Two systems. Neutrals carry the interface; the Enviolo ramp carries the brand. Brand colours never go on buttons, text or borders.

Enviolo ramp Draft

Light to dark, like the sky: warm at sunset, cold at midnight. Use it for gradients, chart bars and volumetric effects. Select a swatch to copy its hex.

Gradients

Numbers refer to ramp steps (var(--enviolo-200)). Use one gradient per view, for a brand moment. Copy CSS gives the full declaration.

Charts

Series follow the ramp order, lightest first. Light mode uses 100, 200, 400, 600, 900; dark mode shifts to 50, 100, 200, 400, 500 so bars stay visible on dark surfaces. The pale steps (Ivory, Apricot) have weak contrast against their background, so always label the bars.

Status colours

Tailwind v4.3 primitives, mapped to semantic status tokens. Each status pairs a pale background with a strong text step, so contrast holds in both modes. Status colours carry meaning only: errors, warnings, success and information, never decoration. Select a swatch to copy its hex.

Backgrounds and text are solid ramp steps, so they match Figma one to one: --{status}-bg is step 50 in light mode and 950 in dark mode, --{status}-text is step 700 in light and 300 in dark. The status token itself is for fills, icons and borders.
