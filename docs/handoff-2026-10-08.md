## Key decisions made in this session

- **Architecture**: shadcn/ui is the backbone for React apps and Basecoat for the web. Both share shadcn token names and the **Luma** style, with an **Enviolo token layer** on top that changes values, never names. Figma mirrors this through the shadcncraft kit.
- **Defaults**: match system theme, Source Sans 3, Source Code Pro, Tabler icons, Taupe neutrals (light) and Mist neutrals (dark).
- **Enviolo colour ramp** (draft, 11 steps, sunset → midnight): Ivory, Apricot, Coral, Copper, Clay, Dusk, Twilight, Coffee, **Nightfall** (new, OKLab midpoint `#20262B`), Midnight, Pearl Black.
- **Per-mode settings**: background, accent (hover/muted fills) and focus (`--ring`, active fields), each set per mode through optional override variables.
- **Status colours**: Tailwind red, amber, green and blue primitives, mapped to `--destructive`, `--success`, `--warning`, `--info`, with a `--status-tint` opacity token.
- **Buttons**: four types (primary, secondary, outline, ghost) plus link and destructive. Secondary and outline share rank 2; the surface decides between them.
- **Layout**: 4/8/12 columns at 600/880px, 1080px container.

## Prototype vs production

The prototype is a single HTML file built for the documentation site. It differs from production in these ways:
- Dark mode uses `data-theme` there; **production uses the `.dark` class** (shadcn/Basecoat convention). `tokens.css` already uses `.dark`.
- Button classes are written as `btn btn-sm btn-outline`. **Basecoat likely combines size and variant** (e.g. `btn-sm-outline`); verify against the Basecoat docs.
- Neutral ramp switching and the Display menu are for exploration. Production ships the defaults only.
- The CSS is hand-written to mimic Basecoat; no library is loaded.

## Open decisions (also in design.md §15)

1. Light-mode focus: Coral is 2.3:1 on white (below the 3:1 minimum). Switch the default to Copper (3.1:1)?
2. Dark-mode focus: make Ivory the default?
3. Status backgrounds: transparent tints (current) or solid ramp steps for Figma parity?
4. Final name for Enviolo 800 ("Nightfall" for now).
5. A dedicated `--highlight` token for featured cards, so they stop borrowing `--ring`.
6. Publish the Enviolo ramp to the brand guidelines.
7. Which product adopts the system first.
