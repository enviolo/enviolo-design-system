Desktop880px and up1224px24pxContainer caps at 1080px and centres.

Tailwind's defaults are 640, 768 and 1024px. Enviolo uses content-driven breakpoints, set as custom tokens:

@theme { --breakpoint-sm: 37.5rem; /* 600px, tablet */ --breakpoint-md: 55rem; /* 880px, desktop */ --container-content: 67.5rem; /* 1080px */ }
