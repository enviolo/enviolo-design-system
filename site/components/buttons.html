Buttons

Displays a button or a component that looks like a button. Variants set emphasis; sizes set height.

<button class="btn" data-variant="outline">Button</button>

Usage

Plain HTML uses a base class plus attributes. React uses shadcn/ui's Button with the same variant names.

Include CSS

<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="tokens/components.css">

Add your button HTML

<button type="button" class="btn" data-variant="outline" data-size="sm">Preview</button>

Omit data-variant for the default button and data-size for the default size. Use <button> for actions and <a class="btn"> for navigation.

React (shadcn/ui)

import { Button } from "@/components/ui/button"

<Button>Find a dealer</Button>
<Button variant="outline" size="sm">Preview</Button>
<Button variant="ghost" size="icon" aria-label="More options"><MoreIcon /></Button>

Accessibility

  • Icon-only buttons need an accessible name: aria-label, plus title for a hover hint.
  • Disabled uses the native disabled attribute. It drops to 45% opacity and is not focusable.
  • Decorative icons get aria-hidden="true".
  • A loading state isn't defined yet. Shadcn and Basecoat show a spinner inside a disabled button; add one here when a product needs it.

States

Hover is a solid fill from a token (default moves two ramp steps, the others one), focus uses the focus colour from the Display menu, disabled drops to 45% opacity. Focus is a solid 2px ring with a 2px offset, not shadcn's border plus 3px halo: Copper only clears 3:1 on white at full opacity, and a 50% halo would drop to about 1.7:1.
