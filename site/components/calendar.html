Calendar

A dependency-free range calendar, <enviolo-calendar>: no React, themed entirely with tokens. Days are pills; the range between them is a solid band with rounded caps.

Live

Click a day to start a range, click again to end it. Arrow keys move the roving focus.

Anatomy

Pill days

Each day is a 36px circular button, the same radius language as buttons. Selected ends are solid --primary pills.

Accent band

Days between the two ends sit on an --accent band painted on the table cell, not the button, so it stays unbroken across a week.

Rounded caps

The band gets rounded corners wherever a run of days starts or ends: at the range ends, week edges and month edges.

Quiet today

Today gets a 1px --border ring, never a fill, so it never competes with a selected range.

Hover follows the button rules

A solid fill from a token, never an opacity change (design.md 7.1).

Keyboard

WAI-ARIA grid pattern. One day holds a roving tabindex.

KeyDoes
↑ ↓ ← →Move focus by a day or a week
Home / EndJump to the week's first / last day
Page Up / Page DownStep a month; with Shift, a year
Enter / SpacePick: first press starts the range, second ends it
EscCancel a half-picked range and restore the previous one

API

AttributeValues
months1 or 2 visible months (default 2)
week-start0 Sunday, 1 Monday (default 1)
localeBCP 47 tag for month and weekday names
min / maxISO dates; days outside are disabled
todayISO date to mark as today (default: the real today)

Property range = {from, to} (setting it never fires change). Event change fires once a complete range is picked, with detail = {from, to}.

React apps use shadcn's Calendar (react-day-picker) instead; both read the same tokens.
